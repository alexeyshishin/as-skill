# content-factory

Из одного источника делает весь пакет контента за проход: статью 1500–2500 слов, 10 тредов, 5 сценариев Reels, 5 постов, 3 карусели и контент-план — шестью отдельными файлами.

## Когда срабатывает

«Контент-завод», «размножь видео на контент», «нарежь сценарий на посты, рилсы и карусели», «сделай контент из транскрипции».

## Что делает

На входе принимает готовую статью или транскрипцию видео. Если есть только тема — предлагает сначала собрать исходник исследованием.

Ключевая часть — матрица углов: каждая единица контента получает свой угол подачи, поэтому десять тредов не оказываются десятью пересказами одного тезиса. Каждый текст проходит антиИИ-фильтр и проверку на сохранение авторского голоса.

## Границы

Не выдумывает факты сверх того, что есть в источнике. Не публикует. Самый крупный скилл коллекции и единственный, который пишет несколько файлов за раз, — запускать стоит осознанно.
