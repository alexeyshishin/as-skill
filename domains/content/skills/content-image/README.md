# content-image

Делает картинки для постов в стиле автора: белый холст 1920×1920, чёрный Roboto, эмодзи в заголовках. Figma при работе не нужна: цвета, шрифты и отступы сняты с макета один раз и лежат в `references/tokens.css`.

## Когда срабатывает

«Сделай картинку к посту», «обложка для поста», «карточка с текстом», «картинка для канала».

## Что делает

Два шаблона:

- `title` — крупный заголовок с эмодзи или логотипом справа, необязательный подзаголовок под ним.
- `text` — 1–3 абзаца Roboto Light с жирными кусками, эмодзи прямо в тексте и хэндлом автора внизу.

Заголовок и подзаголовок карточки `title` всегда на английском и строчными, как во всех кадрах Figma. Русский заголовок скилл сам переводит одним коротким словом, а скрипт кириллицу в них не принимает. Текст на странице `text` остаётся на языке автора.

Скрипт `scripts/render.py` подставляет текст в шаблон и снимает PNG через headless Chrome. Если заголовок или текст не помещаются на холст, он отказывается рендерить и говорит, что именно не влезло. Результат совпадает с макетом Figma с точностью 1–2 px.

## Требования

Python 3 и Chrome или Chromium. Если Chrome лежит в нестандартном месте, путь задаётся через `CHROME_BIN`. Эмодзи берутся из системного шрифта: на macOS это Apple Color Emoji, как в макете. На Linux и Windows картинки выйдут с другим набором эмодзи. Хэндл автора передаётся флагом `--handle` или переменной `CONTENT_IMAGE_HANDLE`.

## Границы

Только эти два шаблона: диаграммы, графики и фото-коллажи скилл не делает. Текст берёт у автора как есть, сам не пишет и никуда не публикует.

Шрифт Roboto лежит в `references/fonts/` под лицензией Apache 2.0 (`LICENSE-Roboto`).

Текст поста — `content-tg-post`, статья — `content-article-draft`, пакет форматов из одного источника — `content-zavod`.
