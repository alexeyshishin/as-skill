# content-documentation

Строит скелет технического туториала: prerequisites, цель «после прочтения сможешь X», нумерованные шаги с командами и проверками, troubleshooting, cleanup.

## Когда срабатывает

«Написать туториал», «оформить пошаговую инструкцию», «how-to», «гайд по развёртыванию», «инструкция, как сделать X».

## Что делает

Определяет scope и формулирует, что читатель сможет после прочтения. Разбивает путь на шаги, где у каждого есть команда и способ проверить, что она сработала. Отдельно выносит troubleshooting и cleanup — то, что авторы забывают чаще всего.

## Границы

Намеренно не пишет полный текст: отдаёт корректный скелет, в который автор досыпает детали. Скелет без деталей полезнее, чем гладкий текст с выдуманными командами.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`content`](../../../../docs/domains/content/README.md).
