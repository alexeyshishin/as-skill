# obsidian-note-critic

Критикует заметку с опорой на базу: ищет похожие и противоположные, находит противоречия с уже записанным, разбирает аргументацию.

## Когда срабатывает

«Покритикуй заметку», «найди противоречия», «что я упустил», «чего не хватает», «сделай peer review».

## Что делает

Гибридный поиск по базе даёт две группы: заметки о том же и заметки с противоположным взглядом. Дальше сверяет утверждения новой заметки с тем, что уже записано, и показывает места, где они расходятся.

Противоречие с собственной старой заметкой — самая ценная находка: значит, либо взгляд изменился и это стоит зафиксировать, либо одна из двух неверна.

## Границы

Не правит заметку — только показывает. Решение, что делать с найденным, за автором.
