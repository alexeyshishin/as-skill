# git-conventional-commits

Пишет commit-сообщение по Conventional Commits для текущих изменений.

## Когда срабатывает

«Сделать коммит», «закоммитить изменения», «сформулируй commit-message», «commit по конвенции».

## Что делает

Читает staged-diff (а если staged пуст — unstaged), определяет type и scope по содержимому изменений, формулирует subject в императиве. Сообщение — одна строка: без тела, описания, списка и футера. Показывает готовое сообщение и ждёт подтверждения перед `git commit`.

## Границы

Не коммитит без подтверждения. Не пишет тело коммита, даже «короткое» и даже для большого изменения: большое изменение — это несколько коммитов, а breaking change — это `!` в заголовке, остальное уходит в PR. Не пишет `chore: update` — пустое сообщение хуже отсутствующего. Никаких трейлеров и следов Claude в сообщении (`Co-Authored-By`, ссылки на сессию) — см. [`git-conventions`](../../rules/git-conventions.md#no-ai-attribution).

## Чем укомплектован

[`references/commit-examples.md`](references/commit-examples.md) — корпус реальных коммитов из 10 репозиториев автора (155 коммитов, срез на 26.10.2026): распределение type/scope, чистые примеры по каждому типу и анти-паттерны, отранжированные по фактической частоте. 84% коммитов автора — одна строка. Самый частый промах — тело или футер, которых быть не должно (23), затем docs-only диффы под `chore`/`feat` (10), неатомарные subject через «and» (7) и прошедшее время вместо императива (5).

[`scripts/lint-commit-msg.py`](scripts/lint-commit-msg.py) — линтер сообщения: разбирает заголовок, проверяет type/scope/длину/наклонение, любое тело или футер после заголовка (`body-present` — ошибка), запрещённые AI-трейлеры. Без зависимостей, Python 3.8+.

```bash
python3 scripts/lint-commit-msg.py -                # сообщение на stdin
python3 scripts/lint-commit-msg.py .git/COMMIT_EDITMSG
python3 scripts/lint-commit-msg.py --history 50     # аудит лога репозитория
```

Коды выхода: 0 — чисто, 2 — есть ошибки (с `--strict` ещё и предупреждения), 1 — ошибка вызова. Годится как `commit-msg` hook без обёртки. Линтер проверяет форму, не истину: соответствие type сути диффа и осмысленность subject остаются за моделью и автором.

Конвенция целиком — в правиле [`git-conventions`](../../rules/git-conventions.md).
