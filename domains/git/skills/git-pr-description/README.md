# git-pr-description

Делает описание Pull Request из diff текущей ветки против базовой.

## Когда срабатывает

«Описать PR», «оформить пуллреквест», «сгенерируй PR description».

## Что делает

Собирает все коммиты ветки и разворачивает их в три вопроса, на которые ревьюер хочет получить ответ до чтения кода: зачем это делается, что изменилось по слоям, как проверить. Breaking changes выносит отдельным разделом, а не прячет в списке изменений.

## Границы

Не открывает PR и не пушит без явного подтверждения. Не пересказывает diff построчно: ревьюер и так его увидит, ему нужен контекст.
