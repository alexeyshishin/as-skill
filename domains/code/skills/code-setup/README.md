# code-setup

Устанавливает этот мини dev-loop harness (`/plan → /build → /review`, с `/debug` в петле) в целевой проект: копирует агентов, скиллы, test-gate хук, настройки и `AGENTS.md`, при необходимости сеет стартовый Memory Bank.

## Когда срабатывает

`/setup <абсолютный-путь-к-проекту>` — запускается из клона этого репозитория, путь указывает пользователь; без пути скилл его запрашивает, а не угадывает.

## Что делает

Проверяет, что целевой путь существует, не совпадает с исходным репозиторием и является git-репозиторием (если нет — предлагает `git init`, но не инициализирует без подтверждения). Копирует агентов, скиллы `plan/build/review/debug` (но не `setup` — цель не переустанавливает сама себя), hook'и с `chmod +x` и `swarm-report/` с `.gitkeep`. `settings.json` не перезаписывает, а мёржит Stop-хуки в существующий файл через `jq`, с дедупликацией по command string.

Memory Bank сеет только если его ещё нет — если уже есть, оставляет как есть, даже при повторном запуске.

## Границы

Только перекладывает файлы: ничего не собирает и не правит в пользовательском коде. Идемпотентен для агентов/скиллов/хука, но никогда не трогает `.memory-bank/` и хуки пользователя, которых не касается сам харнесс.
