# docs-humanizer

Убирает из текста следы AI-генерации. Два режима: проверка README на нейрослоп (английский и русский) и полное очеловечивание русскоязычного текста.

## Когда срабатывает

«Проверь README на нейрослоп», «убери нейрослоп из README», «очеловечить текст», «убрать следы нейросети», «звучит как робот», «убрать канцелярит». README-режим вызывают и сами `docs-readme`, `docs-readme-writer`, `docs-readme-reviewer`.

## Что делает

**README-режим** — для `README.md` и `README_RUS.md`. Сканер находит маркеры, затем модель дочитывает то, что регексу не видно: утверждения без цифр, Features из прилагательных, Why, пересказывающий заголовок. Правит только помеченные фрагменты и только в техническом регистре: маркетинговое прилагательное заменяется измеренным фактом или удаляется. Код, команды, ссылки и структура не трогаются, правка в EN зеркалится в RU. Цикл: скан → правка → повторный скан со сравнением → гейт 1.5 маркера на 100 слов. Ревьюер получает находки, не правки.

**Полный режим** — для русских постов, статей, писем. Работает от каталога тэллов, классифицирует текст по регистру и возвращает авторский ритм. Цикл тот же: сканирование и повторная проверка, потому что переписывающая модель заносит те же признаки обратно в парафразе.

## Границы

Английский — только в README-режиме; полное очеловечивание английского текста вне задач скилла. Не переводит, не пишет с нуля, не правит грамматику как самоцель и не трогает код. Авторские шероховатости в полном режиме — не ошибки: сглаживать их означает вернуть текст туда, откуда его вытаскивают.

Основан на `content-humanizer` из домена `content`. Тот остаётся там для постов и статей; этот — для README и документации, полный режим здесь нужен проектам, где стоит только `docs`.

## Чем укомплектован

[`scripts/scan-tells.py`](scripts/scan-tells.py) — регексный сканер: русский и английский каталоги (язык определяется по доле кириллицы), режим Markdown для `.md` (код, ссылки, HTML, URL не сканируются; добавляются тэллы README — эмодзи в заголовках и пунктах, списки `**Метка:**`, «Добро пожаловать»), плотность на 100 слов и вердикт, сравнение «до/после» с выводом добавленных при переписывании маркеров, гейт `--max-density`. Без зависимостей, Python 3.8+.

```bash
python3 scripts/scan-tells.py README.md
python3 scripts/scan-tells.py README_RUS.md --max-density 1.5
python3 scripts/scan-tells.py before/README.md README.md
```

Замеры на 17.11.2026: `README.md` этого репозитория — 0.24, `README_RUS.md` — 0.30, `tools/README.md` — 0.30; нарочно «нейрослоповый» README — 48.65 (EN) и 54.39 (RU). Два репозитория — не калибровочный корпус, пороги — ориентир.

[`references/tells-en.md`](references/tells-en.md) — английский каталог по [Wikipedia: Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) плюс тэллы README. [`references/tells-ru.md`](references/tells-ru.md) — русский каталог и пороги.
