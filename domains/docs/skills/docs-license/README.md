# docs-license

Подбирает лицензию, кладёт в проект её дословный текст и оформляет атрибуцию чужого кода.

## Когда срабатывает

«Выбери лицензию», «добавь лицензию», «какую лицензию взять», «создай LICENSE», «оформи атрибуцию».

## Что делает

**Подбор.** Короткий опросник: можно ли использовать код в закрытых продуктах, важен ли патентный грант, насколько далеко должен тянуться copyleft, что принято в экосистеме. На выходе — один SPDX id и максимум одна альтернатива, у каждой причина в одну строку. Решает пользователь.

**Файл.** Текст лицензии никогда не набирается моделью: он копируется из `references/licenses/` (15 канонических текстов из GitHub license API) или скачивается (`gh api /licenses/<key>`, запасной вариант — SPDX license-list-data). Правятся только плейсхолдеры `[year]` и `[fullname]`; правообладателя спрашивает, по умолчанию предлагает `git config user.name`. Секцию License в `README.md` / `README_RUS.md` приводит к виду `[<SPDX>](LICENSE)`, остальной README не трогает.

**Атрибуция.** Для скопированного, вендоренного или адаптированного кода: исходник, лицензия, копирайт, дословный текст лицензии апстрима в `LICENSE-<Upstream>` или рядом с кодом, запись в `NOTICE`, строка-кредит в README. Проверяет совместимость лицензии апстрима с лицензией проекта по таблице.

## Границы

Не юридическая консультация: рекомендует, называет причину, для смены лицензии, CLA, смешения GPL с проприетарным кодом и патентов прямо говорит «к юристу». Не правит манифесты (`license` в `package.json` и т.п.) и не расставляет SPDX-заголовки в файлах — только сообщает о расхождении. Ревью существующего лицензирования — агент `docs-license-reviewer`, правки по ревью — `docs-license-writer`. Не коммитит.

## Чем укомплектован

[`references/licenses/`](references/licenses/) — AGPL-3.0, Apache-2.0, BSD-2-Clause, BSD-3-Clause, BSL-1.0, CC0-1.0, EPL-2.0, GPL-2.0, GPL-3.0, ISC, LGPL-2.1, LGPL-3.0, MIT, MPL-2.0, Unlicense — дословно из `gh api /licenses/<key>` (срез 16.11.2026).

[`references/choose-license.md`](references/choose-license.md) — опросник, таблица лицензий, конвенции экосистем, когда отправлять к юристу.

[`references/third-party.md`](references/third-party.md) — что считается чужим кодом, куда класть его лицензию, таблица совместимости.

[`scripts/check-license.py`](scripts/check-license.py) — сверяет файл лицензии с каноническим текстом пословно (регистр, пробелы, кавычки и `(c)` не важны), определяет SPDX автоматически, ловит незаполненные плейсхолдеры, изменённые формулировки, год в будущем, LGPL-3.0 без GPL-3.0, расхождение с секцией License в README (EN и RU) и с полем `license` в манифестах. Без зависимостей, Python 3.8+.

```bash
python3 scripts/check-license.py                       # все LICENSE*/COPYING* в текущей папке
python3 scripts/check-license.py LICENSE --spdx MIT
python3 scripts/check-license.py LICENSE --canonical canon.txt --placeholder "<year>"
python3 scripts/check-license.py --list
```

Коды выхода: 0 — чисто, 2 — есть ошибки (с `--strict` ещё и предупреждения), 1 — ошибка вызова.
