# university-md-to-docx

Превращает ВКР, написанную в Markdown, в `.docx` по ГОСТ 7.32 и проверяет результат.

## Когда срабатывает

«Оформи диплом по ГОСТ», «сделай docx из markdown», «конвертируй ВКР в Word», «проверь оформление docx».

## Что делает

Берёт `.md` с frontmatter (данные титульного листа) и собирает документ: титульный лист в отдельной секции без номера страницы, содержание полем TOC, разделы и подразделы с автонумерацией, каждый раздел с новой страницы, подписи «Рисунок N – …» под рисунками и «Таблица N – …» над таблицами, формулы с номером справа, перечисления, список источников, приложения с буквами А, Б, В. Поля 30/15/20/20 мм, Times New Roman 14, интервал 1,5, отступ 1,25 см, выравнивание по ширине, номер страницы внизу по центру.

Потом прогоняет `.docx` через проверку: поля, шрифт, интервал, структурные элементы, нумерацию заголовков, подписи и ссылки на рисунки, таблицы и приложения, соответствие `[N]` списку источников, оставшиеся плейсхолдеры.

## Границы

Следует ГОСТ 7.32, а не методичке конкретного вуза: если вуз требует иного, это нужно сказать до конвертации. Не придумывает ФИО, группу, кафедру, год. Не правит `.docx` вручную: исправления идут в исходный `.md`. Не генерирует «Продолжение таблицы», лист подписей, английскую аннотацию и справку об оригинальности. Содержание и номера страниц — поля Word: при открытии файла нужно согласиться на обновление полей.

## Чем укомплектован

[`references/md-conventions.md`](references/md-conventions.md) — как размечать в Markdown титул, заголовки, рисунки, таблицы, формулы и перекрёстные ссылки.

[`scripts/md2docx.py`](scripts/md2docx.py) — конвертер. Зависимость: `python-docx`, Python 3.8+.

```bash
python3 scripts/md2docx.py thesis.md -o thesis.docx
python3 scripts/md2docx.py thesis.md --strict   # любое предупреждение — код 2
```

[`scripts/check-docx.py`](scripts/check-docx.py) — механическая проверка готового `.docx`. Коды выхода: 0 — чисто, 2 — есть ошибки, 1 — ошибка вызова. Проверяет форму, не смысл: качество текста и реальность источников остаются за `university-reviewer`.

```bash
python3 scripts/check-docx.py thesis.docx
```
