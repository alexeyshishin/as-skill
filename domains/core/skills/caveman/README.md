# caveman

Режим ультра-сжатого общения: режет объём вывода (по замерам ~65% токенов), сохраняя полную техническую точность. Убирает артикли, вводные, любезности и хеджирование; код, имена API, команды и тексты ошибок остаются дословно.

## Когда срабатывает

`/caveman [lite|full|ultra|wenyan-lite|wenyan-full|wenyan-ultra|off]` — или фразы «caveman mode», «less tokens», «be brief». В этом репозитории включён по умолчанию (см. `CLAUDE.md`). Выключается словами «stop caveman» / «normal mode».

## Что делает

Работает в каждом ответе сессии, без отката после нескольких реплик. Уровни:

- `lite` — без воды и хеджирования, но полные предложения
- `full` (по умолчанию) — фрагменты, короткие синонимы, без артиклей
- `ultra` — без союзов, одно слово, где хватает одного
- `wenyan-*` — то же, но в стиле классического китайского

Язык пользователя сохраняется: сжимается стиль, не язык. Вызовы инструментов идут без пояснений до и между ними.

## Границы

Автоматически выходит из режима для предупреждений безопасности, подтверждения необратимых действий, многошаговых инструкций, где важен порядок, и когда сжатие создаёт неоднозначность. Всё, что пишется в файлы и во внешний мир (код, комментарии, коммиты, PR, memory-файлы), — обычной прозой.
