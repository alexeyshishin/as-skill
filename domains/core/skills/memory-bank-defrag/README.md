# memory-bank-defrag

Дефрагментация базы знаний проекта: сворачивает цепочки «поправка на поправку» в чистое текущее состояние, закрывает решённые вопросы, исправляет устаревшие факты и обновляет auto-memory. Те же факты, меньше патчей.

## Когда срабатывает

`/memory-bank-defrag [baseline-ref]` — или «defrag the memory bank», «актуализируй .assistant», «причеши базу знаний». Необязательный `baseline-ref` (например `HEAD~20` или SHA) переопределяет автоопределённую точку отсчёта.

## Что делает

1. Находит коммит прошлой дефрагментации по трейлеру `Memory-Defrag:` (запасной вариант — subject `actualize memory bank`).
2. Собирает коммиты и диффы с тех пор. Если ничего существенного не менялось — выходит без правок.
3. Читает `.assistant/`, auto-memory (`~/.claude/projects/<slug>/memory/`, если есть; только Claude Code) и текущие доки вроде `README.md`.
4. Ищет расхождения: устаревшие факты, патчи для свёртки, закрываемые вопросы, битые ссылки, незафиксированные решения — каждое с доказательством (SHA, `file:line`).
5. Правит, проверяет `grep`-ом остатки ретайрнутого, показывает diff и сводку.

Факты проверяются по живому репозиторию: если память противоречит коду, верен код.

## Границы

Меняет только документацию и знания, продуктовый код не трогает. Сырые источники (транскрипты, дампы чатов) остаются дословными. Ничего не выдумывает и не пишет в историю «актуализировано такого-то числа». Без явной просьбы не коммитит. В unattended-режиме открывает PR из ветки `memory-defrag/<YYYY-MM-DD>`, в `main` не пушит, а при необходимости шлёт короткий отчёт в Mattermost через `MM_DEFRAG_WEBHOOK`.
