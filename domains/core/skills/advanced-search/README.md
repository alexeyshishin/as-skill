# advanced-search

Глубокий веб-поиск с фактчекингом в роли OSINT-исследователя: самые свежие данные, только авторитетные источники, противоречия показаны с обеих сторон, ответ легко сканировать глазами.

## Когда срабатывает

`/advanced-search <тема>` — или фразы «поищи», «найди», «проверь факт», «research», «fact-check».

## Что делает

- Разбивает тему на подвопросы, ищет параллельно, открывает первоисточники, а не верит сниппетам
- Свежесть — относительно текущей даты; для быстро меняющихся данных указывает дату последнего изменения
- Ключевые тезисы подтверждает минимум двумя независимыми источниками; игнорирует кликбейт и рекламные блоги
- Формат ответа: главный вывод одним жирным предложением, маркированные списки без воды, таблица при сравнении больше двух параметров, кликабельные ссылки на первоисточники

## Границы

Не выдумывает ссылки, цифры и даты — что не нашлось или не подтвердилось, помечается явно. Нужны инструменты `WebSearch`/`WebFetch`.
